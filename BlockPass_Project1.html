Ticket inventory

Scan QR or enter ticket ID

Scan a ticket using this website. BlockPass checks the scanned ID against its saved ticket inventory and displays VALID or INVALID. A valid unused ticket is redeemed; unknown or previously redeemed tickets are rejected. Camera access requires HTTPS or localhost.

Or enter ticket ID manually

Redeemed tickets cannot be used again.

Verification rules

1. Ticket ID must exist in the inventory.

2. Ticket must not have been redeemed already.

3. Successful redemption is saved in browser storage.

Audit summary

Project status

Working demo: event creation, ticket inventory, one-time redemption, resale simulation, audit history and browser storage.

QR codes contain ticket IDs. The Verify Entry scanner checks each scanned ID against this browser’s saved inventory and displays VALID or INVALID, then redeems valid unused tickets. Camera permission and internet access for the scanner library may be required. Data is local to this browser and is not shared between devices. This is not connected to a real blockchain, server database or payment service.
