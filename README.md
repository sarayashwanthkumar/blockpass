# BlockPass — Complete Connected Team Project

## Technologies
HTML, CSS, JavaScript, browser localStorage, and the html5-qrcode library loaded from a CDN.

## Run in VS Code
1. Extract this ZIP.
2. Open this folder in VS Code using File → Open Folder.
3. Install the Live Server extension if needed.
4. Right-click `index.html` → Open with Live Server.
5. Allow camera permission for QR scanning. QR scanning requires localhost/HTTPS and an internet connection to load the scanner library.

## Team assignments
- Person 1 — `js/events.js`: create events and issue tickets.
- Person 2 — `js/verification.js`: manual verification, one-time redemption, duplicate blocking, and QR scanner.
- Person 3 — `js/resale.js`: transfer ticket ownership and save transfer history.
- Person 4 — `js/audit.js`: privacy mode, export JSON, reset demo data.
- Person 5 — `js/dashboard.js`: dashboard rendering, navigation, and ticket helper.
- Shared integration file — `js/app.js`: shared state, localStorage, escaping, messages, and activity log.
- `index.html`: all page markup, original CSS, and script connections.

## Important integration note
Open `index.html` to run the whole project. The individual `.js` files are modules used by the website; they are not standalone websites and rely on `js/app.js` plus the HTML elements. Keep the script order at the bottom of `index.html` unchanged.

## Demo limitations
This is a browser-only demonstration. Data is stored in the current browser and is not shared across devices. It is not connected to a real blockchain, server database, or payment service. QR images are generated by an external QR service.
